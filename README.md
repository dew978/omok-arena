# 오목 아레나 — 렌주룰 클래스 랭크 리그

학생 25명이 태블릿으로 오목을 두며 티어 경쟁을 하고, 선생님(master)은 PC에서 경기를 배정하고 실시간으로 관전하는 웹앱입니다.
**직접 운영하는 서버가 없습니다.** 파일은 무료 정적 호스팅에, 데이터는 Firebase 무료 요금제에 저장합니다.

---

## 1. 먼저 데모로 체험하기 (설정 없이)

`js/firebase-config.js`가 비어 있으면(`null`) **데모 모드**로 동작합니다. 데이터는 그 브라우저 안에만 저장됩니다.

1. 폴더에서 PowerShell을 열고 `.\serve.ps1` 실행
   (실행이 막히면 `powershell -ExecutionPolicy Bypass -File .\serve.ps1`)
2. 브라우저에서 `http://localhost:8765` 접속 → 관리자 비밀번호를 정해 **관리자 계정 만들기**
3. 「학생 관리」에서 학생 몇 명 등록
4. **새 탭**을 열어 학생 아이디로 로그인 → 탭을 여러 개 열면 서로 대전을 시험할 수 있어요

> 데모 모드에서는 태블릿끼리 연결되지 않습니다. 실제 수업에는 아래 2~3단계를 진행하세요.

---

## 2. Firebase 설정 (무료, 약 10분)

1. <https://console.firebase.google.com> → **프로젝트 추가** (Google Analytics는 꺼도 됩니다)
2. **Authentication** → 시작하기 → 로그인 방법 → **이메일/비밀번호** 사용 설정
   - 학생 아이디는 내부적으로 `아이디@omok.example.com` 형태의 가짜 이메일로 저장됩니다. 실제 메일은 보내지 않습니다.
3. **Realtime Database** → 데이터베이스 만들기 → 위치 **싱가포르(asia-southeast1)** → 잠금 모드로 시작
   - **규칙** 탭에 이 폴더의 `database.rules.json` 내용을 전부 붙여넣고 **게시**
4. 프로젝트 설정(⚙️) → 일반 → 내 앱 → **웹 앱(</>) 추가** → 표시되는 `firebaseConfig` 값을
   `js/firebase-config.js`의 `window.OMOK_FIREBASE_CONFIG = { ... }`에 붙여넣기
   - `databaseURL` 항목이 꼭 있어야 합니다. 없으면 Realtime Database 화면 상단의 주소를 넣으세요.

## 3. 인터넷에 올리기 — GitHub Pages (무료)

1. <https://github.com/new> 에서 새 저장소 만들기 (예: `omok-arena`, **Public**)
   - 무료 계정은 Public 저장소만 Pages를 쓸 수 있습니다. 코드와 Firebase 설정값이 공개되지만,
     Firebase 설정값은 비밀번호가 아니며 접근은 `database.rules.json` 보안 규칙이 막습니다.
     학생 비밀번호·점수는 저장소가 아니라 Firebase에 저장되므로 공개되지 않습니다.
2. 저장소 화면에서 **Add file → Upload files** → 이 폴더 안의 파일·폴더를 전부 끌어다 놓기 → **Commit changes**
   (`index.html`이 저장소 맨 위에 있어야 합니다)
3. **Settings → Pages** → Source: **Deploy from a branch** → Branch: `main` / `/(root)` → Save
4. 1~2분 뒤 `https://아이디.github.io/omok-arena/` 주소가 생깁니다
5. **Firebase → Authentication → 설정 → 승인된 도메인**에 `아이디.github.io` 를 추가

파일을 고쳐 다시 올리면 몇 분 뒤 반영됩니다(태블릿에서는 새로고침). 주소를 바꾸지 않는 한 데이터는 그대로 유지됩니다.

> 다른 무료 방법: Firebase Hosting(이미 쓰는 Firebase에 같이 올림, 단 Node.js 설치 필요), Cloudflare Pages.

## 4. 여러 반 운영

한 사이트에서 여러 반이 **완전히 따로** 씁니다. (반마다 학생 최대 25명, 순위·챔피언·대전·기록 모두 반 안에서만)

| 역할 | 로그인 | 하는 일 |
|---|---|---|
| **총관리자** | 반 코드 비움 + `master` | 가입 코드 정하기, 반 목록·학생 수 보기, 아무 반이나 들어가 관리, 반 삭제 |
| **반 관리자(선생님)** | 반 코드 + 관리자 아이디 | 자기 반 학생 등록·경기 배정·관전·설정·시즌 |
| **학생** | 반 코드 + 아이디 | 자기 반 안에서 경기 |

1. 처음 접속하면 **총관리자 계정 만들기** 화면이 나옵니다. 아이디는 `master`로 고정입니다.
2. 총관리자로 로그인 → 「🏫 반 관리」에서 **가입 코드**를 정해 저장합니다. (정하기 전에는 아무도 반을 만들 수 없어요)
3. 선생님은 로그인 화면의 **「선생님: 새 반 만들기」** → 가입 코드, 반 이름, **반 코드**(예: `3-2`), 관리자 아이디·비밀번호 입력 → 바로 반 관리자 화면으로 들어갑니다.
   - 반 코드는 학생들이 로그인할 때 입력하는 짧은 코드이며 나중에 바꿀 수 없습니다. 반 이름은 설정에서 바꿀 수 있어요.
   - 반마다 아이디가 따로라서 1반과 2반에 똑같은 `kim01`이 있어도 됩니다.
4. 태블릿은 반 코드를 한 번 입력하면 기억합니다.
5. **동시 접속 한도**: Firebase 무료 요금제는 동시 접속 100명 → 25명 반 기준 **4개 반까지 동시에** 수업 가능. 더 필요하면 Firebase를 종량제(Blaze)로 바꾸세요.
6. 반을 삭제하면 그 반 학생 계정·점수·기록이 모두 지워집니다. 선생님 로그인 계정은 남는데, 같은 반 코드를 같은 관리자 아이디·비밀번호로 다시 만들면 그 계정을 다시 씁니다.

## 5. 반 관리자 화면

1. 「학생 관리」 → 여러 명 한꺼번에 등록: 한 줄에 `아이디,이름,비밀번호` (비밀번호를 비우면 6자리 숫자가 자동으로 만들어짐)
2. 학생들에게 주소, **반 코드**, 아이디·비밀번호를 나눠 주세요. 태블릿에서는 **홈 화면에 추가**하면 앱처럼 쓸 수 있어요.
3. 관리자 화면
   - **실시간 경기**: 진행 중인 경기가 미니 오목판으로 보이고, 누르면 큰 화면으로 관전 (경기 무효 처리 가능)
   - **매치 배정**: 두 명을 골라 경기를 만들거나, 접속자 전체(또는 선택한 학생)를 ±1티어 우선으로 랜덤 편성
   - **학생 관리**: 추가·이름/점수 수정·비밀번호 확인/변경·삭제 (반마다 최대 25명)
   - **순위표**: 교실 화면에 띄우기 좋은 큰 순위표와 티어 분포
   - **경기 기록**: 모든 경기, 기보 보기, 부정 경기 **무효 처리**(점수 되돌리기)
   - **설정**: 제한 시간·배율·하루 제한·금수 표시 등 규칙, 시즌 종료 & 챔피언 기록
4. 선생님이 접속하지 않아도 학생들끼리 랭크전·일반전을 할 수 있습니다.

## 6. 경기 규칙 (구현 내용)

### 렌주룰
- 흑(선공)의 **삼삼 · 사사(같은 줄의 X.XXX.X 포함) · 장목**은 금수이며, 두면 **즉시 반칙패**
- 흑은 정확히 5목만 승리. 오목이 되는 수는 금수 모양이 함께 생겨도 승리
- 백은 금수 없음, 장목도 승리
- 열린 3 판정은 "한 수 더 두면 금수가 아닌 열린 4가 되는가"를 재귀적으로 확인 (거짓 삼삼 구분)
- 금수 자리 빨간 X 표시: 기본값은 **일반전에서만** 표시 (설정에서 변경)
- 태블릿 오터치 방지: 기본값은 **두 번 눌러 착수** (첫 터치는 미리보기)

### 경기 종류
| 구분 | 종류 | 점수 |
|---|---|---|
| 랭크전 | 랜덤 매치 (접속자 중 ±1티어 우선, 20초 후 범위 확대) | ×1.0 |
| 랭크전 | 1:1 선택 매치 (상대에게 대결 신청 → 수락) | ×0.7 |
| 랭크전 | 선생님 배정 매치 | ×1.0 |
| 일반전 | AI 대전 (쉬움·보통·어려움, 흑/백/랜덤 선택) | 없음 |
| 일반전 | 친구 대전 | 없음 |

### 점수 (class_omok_rank_system.md 그대로)
- 기본점수 `B = max(18, 49 − 전체 착수 수)` (9수 40점 … 31수 이상 18점)
- 상대 보정 `C`: 경기 전 점수차 기준 +8 / +4 / 0 / −4 / −8
- 변동 = `반올림((B + C) × 매치 배율 × 배치 배율)`
- **배치고사 5판**: ×1.2, 점수·티어 비공개("배치고사 n/5"), 5판째에 `min(1099, 점수)`로 확정하고 티어 공개 연출
- 티어: 브론즈 ≤899 · 실버 900~999 · 골드 1000~1099 · 플래티넘 1100~1174 · 다이아 ≥1175 · **챔피언 = 배치 완료자 중 1위**
- **티어 승급 장면** (`js/tierup.js`, 클래스 티어와 같은 파일): 랭크전 결과로 티어가 오르면 경기마다 한 번, 옛 엠블럼이 작아지며 사라지는 동안 새 엠블럼이 같은 자리에서 커져 들어오고(scale-swap) 새 티어 색 입자가 한 번 터져요(particle-burst). 기기의 「동작 줄이기」가 켜져 있으면 완성 장면만 보여 줘요.
- **1:1 선택 매치**에서 **하루에** 같은 상대와 **연속 3판째부터** 이긴 사람은 0점, 진 사람만 하락 (오늘 둔 랭크전만 세고, 날짜가 바뀌면 다시 1판째)
- **하루 점수 반영 4경기**(배치고사 제외): 초과 경기는 "연습 경기"로 기록, 다음 날 다시 4경기 (설정에서 0으로 두면 무제한)
  - 날짜는 결과를 반영하는 기기의 시각 기준(자정에 바뀜). 예전에 「주당 n경기」로 저장해 둔 반은 같은 수가 「하루 n경기」로 이어집니다.
- 한 수 제한 시간: 랭크전 60초, 일반전 90초. 넘기면 시간 초과 패배

### md 문서의 "미정 사항"을 이렇게 정했습니다 (모두 설정에서 조정 가능한 것은 조정 가능)
| 항목 | 결정 |
|---|---|
| 무승부(판이 가득 참) | 점수 변동 없음 |
| 반칙패 | 일반 승리와 같이 착수 수로 계산 |
| 9수 미만 기권·시간패 | 기본점수 30점 (너무 이른 기권으로 점수를 주고받는 것 방지) |
| 배치 중 학생 vs 배치 완료 학생 | 매칭 허용. 각자 자기 배율 적용(배치 중인 쪽만 ×1.2) |
| 챔피언 동점 | 승수 많은 순 → 패수 적은 순 → 그 점수에 먼저 도달한 순 |
| 챔피언 부여 시점 | 배치 5판을 마친 학생부터 대상 |
| 점수 하한 | 0점 |
| md의 "동일 상대 주 1회·시즌 2회" | 요청하신 "1:1 선택 매치 3연속부터 승점 0" 규칙으로 대체 (연속 수는 하루 단위로 셈) |
| md의 주간 경기 수 제한 | 하루 4경기로 변경 (2026-10) |
| 무효 처리 | 해당 경기의 점수·승패만 되돌림 (이후 경기 보정값은 재계산하지 않음) |
| 시즌 전환 | 「설정 → 시즌」에서 점수 유지 / 전원 1000점 초기화 중 선택 |

## 7. 알아둘 점

- **무료 한도**: Firebase 무료(Spark) 요금제는 동시 접속 100명, 저장 1GB, 월 10GB 전송까지 — 25명 반에는 충분합니다.
- **보안 수준**: 점수 계산이 학생 기기에서 이뤄지므로, 개발자 도구를 다룰 줄 아는 학생이 마음먹으면 이론상 점수를 조작할 수 있습니다. 보안 규칙이 등록된 학생만 접근하게 막고 모든 경기가 「경기 기록」에 남으므로, 수상한 경기는 무효 처리하세요. 완전히 막으려면 Firebase 유료(Blaze) 요금제의 Cloud Functions로 서버 계산이 필요합니다.
- 학생 비밀번호는 선생님이 확인·재발급할 수 있도록 그 반 관리자와 총관리자만 읽을 수 있는 곳에 저장됩니다. 다른 사이트에서 쓰는 비밀번호는 쓰지 말라고 안내하세요.
- 학생이 경기 중에 나가도 「경기로 가기」로 돌아올 수 있습니다. 돌아오지 않으면 제한 시간이 지나 상대가 이깁니다.

```
assets/ink-landscape.jpg 배경 그림 (한자 티어와 같은 수묵 산수, 용량을 줄인 JPG)
js/renju.js             렌주룰 엔진 (승리·금수 판정)

js/rating.js            점수·티어·배치고사 계산
js/backend.js           데이터 저장 (Firebase / 데모)
js/board.js             오목판 그리기
js/tierup.js            티어 승급 장면 (클래스 티어와 같은 파일)
js/app.js               로그인·학생 화면·매칭·경기 진행
js/admin.js             관리자 화면
js/firebase-config.js   ← Firebase 설정값을 붙여넣는 곳
database.rules.json     ← Firebase 보안 규칙
serve.ps1               로컬 테스트용 간이 서버
```
